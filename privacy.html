Privacy policy

This policy describes the personal Plex Drive integration operated by liltinylinux.

Purpose and information accessed

Plex Drive uses rclone on the owner's computer to upload media to Google Drive and make Drive media available for playback through Plex Media Server. The playback connection uses the Google Drive read-only permission (drive.readonly), which permits reading file content and metadata. The upload connection uses drive.file, which permits access to files created or explicitly authorized for this application.

The integration processes file contents, names, folder structure, sizes, modification times and checksums as needed for copying, verification, browsing and playback. OAuth access and refresh tokens authorize these operations.

Storage and use

Uploaded files are stored in the owner's Google Drive account. Originals remain on the owner's computer unless the owner separately removes them. OAuth credentials and tokens are stored in local rclone configuration files. Downloaded media portions may be cached locally. Transfer logs may contain filenames, operational details and error messages. Plex may store local library metadata and playback information under its own settings.

These data are used to operate and troubleshoot the personal media connection. The operator does not sell Google user data or use it for advertising, credit decisions or AI model training.

Sharing and third-party services

File data is exchanged between the owner's computer and Google Drive. Plex handles library discovery and playback according to the owner's Plex configuration. This public documentation website does not host the media, OAuth credentials or transfer logs, and provides no sign-in or file-upload form.

Google, Plex and GitHub process information under their respective policies. GitHub Pages hosts this website and may log visitor IP addresses and request information. This site adds no analytics scripts, advertising or tracking cookies.

Retention and control

Cloud media remains until the owner deletes it in Google Drive, subject to Google's trash and retention behavior. Local originals, configuration files, logs and Plex metadata remain until removed by the owner or the relevant application's retention settings. The playback cache is configured to evict unused data after 24 hours and target a size limit; active files can remain longer.

To stop access, stop the local rclone upload and mount processes and remove this application's connection through Google Account connections. Revocation prevents future authorized access but does not itself delete uploaded files, local copies or caches. The owner can delete those separately.

Contact and changes

For questions, contact the operator through their GitHub profile. Do not disclose credentials or private data in public messages. Changes to the integration's data handling will be reflected here with an updated date.
